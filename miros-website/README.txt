Miro's Glass and Aluminum Services - website

FILES
  index.html   the whole website (no build step, no other files needed)

NOTES
  - The Google Form "Client Inquiry & Order Slip" is embedded in the
    "Send your inquiry or order" section. Responses go to your Google Form as usual.
  - Shop address, phone, email and hours are set in the "EDIT HERE" block
    near the bottom of index.html. Edit them there if anything changes.

PUBLISH ON YOUR OWN WEB SERVER
  Upload index.html to your server's web folder (for example public_html).

PUBLISH ON GITHUB PAGES (free, repo must be public)
  1. Create a public repo and upload index.html to it.
  2. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
  3. Your site will be at https://<username>.github.io/<repo-name>/
